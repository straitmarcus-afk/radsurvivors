# Rad Survivors

A free wasteland horde game. Hold out for ten minutes, then kill the beast that comes for you.

**Play in your browser:** https://straitmarcus-afk.github.io/radsurvivors/play/

**Download for Windows, Mac, Linux and Steam Deck:** https://straitmarcus-afk.github.io/radsurvivors/#download

## What is in this repo

- `site/` the website.
- `dist/rad-survivors.html` the game, as one web page.
- `desktop/` the desktop app wrapper for Windows, Mac and Linux.
- `.github/workflows/` builds the downloads and publishes the site.

Pushing a tag like `v0.3.0` builds every download and attaches them to a release. Pushing to `main` updates the site.

## Fallout 2 files

The game ships with no Fallout art, sound or music. It runs with its own built-in art. If you own Fallout 2, it reads that game's files from your device for the full look. Nothing is uploaded.
